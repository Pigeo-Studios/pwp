# Правила: киты

Часть правил PWP. Полный индекс — корневой `AGENTS.md`.
**Перед изменением кода этого модуля/домена — прочитай этот файл; после изменений (новый модуль/фича, инцидент, фикс, изменённые правила сборки) — обнови его**: текст на русском, метки дат `(дд.мм.2026)`, удаляй устаревшее, если описание разошлось с кодом, секреты/токены не добавлять.

---

- Киты: дизайн в `docs/KITS_SQUAD_DESIGN.md` (Squad-адаптация, 6 фракций: usa/russia/ukraine/nato/insurgency/pmc, bluefor/redfor — заглушки). Генератор `tools/generate_kits.py` (Python, запуск `py -3`) → `maps/kits/<faction>.json` (KitDefinition для `/api/v1/kits/faction/{faction}/bulk`) + `maps/kits/import.sql`. Полная раскладка по слотам — `tools/generate_kits_doc.py` (пишет в `docs/KITS_SQUAD_DESIGN.md`). У всех фракций 19 базовых ролей — роли-варианты (Iron/Red Dot/Optic/Javelin) свернуты, альтернативы оружия лежат внутри кита на слотах 41-42 с маркерами `__ALT__PRIMARY` (выбор в меню деплоя: прицелы у Rifleman/Officer/Medic/LMG/HMG/Marksman, ред-дот у HAT). Альт-труб нет: у всех труб разный боеприпас — LAT/HAT несут одну трубу. M320 у гренадёра — maxstuff (`maxstuff:m320t`, не tacz:m320), патроны `tacz:40mm`. Категории ролей: `DIRECT_COMBAT`/`FIRE_SUPPORT`/`SPECIALIST`/`SUPPORT`; сервер блокирует >3 FIRE_SUPPORT на отряд (меню деплоя + спавн). Лимиты v2 (07.08.2026, под 40 игроков на команду/отряд 9): Officer 6, Medic 10, LAT 6 (команда)/2 (отряд), остальные без изменений (полная таблица — в доке). Описания ролей — ЕДИНЫЙ источник: `description` в БД (конструктор в генераторе: `{фракция} · {роль} — {фраза} · Оружие: {ствол} [+ {труба/M320/Игла}] · Альтернативы: {…}` — фразы в `DESC_PHRASE`, альтернативы перечисляются ТОЛЬКО реально существующие; импорт в БД — ТОЛЬКО через `cmd /c "mysql ... < import.sql"`, НЕ через PowerShell-пайп — тот кодирует stdin в cp866 и бьёт кириллицу). На клиенте: захардкоженный `KIT_META`-фолбэк удалён (07.08.2026), категории/описание приходят только в DTO; русские подписи категорий и названий ролей — `KIT_DISPLAY_NAMES` в `DeployData.java`; описание роли под портретом НЕ рисуется (нет места); метки слотов 0-3 (СТВОЛ/ВТОРИЧКА/ГРАНАТА/СПЕЦ) — по индексу в списке (индекс = слот кита), слоты 4-8 без `__ALT__` — всегда РЮКЗАК (эвристики нет — ракеты/трубы не должны получать метку СТВОЛ). Меню деплоя перебирает все загруженные киты (не хардкод `KIT_NAMES`), API китов — источник истины (старые NBT-киты очищаются при загрузке; при реимпорте `import.sql` старые записи НЕ удаляются — перед импортом нужен `DELETE FROM kit_definitions WHERE kit_name LIKE '% (%)'`). Формат предметов — как в `PacketSaveFactionKit` (tacz: `modern_kinetic_gun`+`GunId`/`AttachmentId`, патроны `tacz:ammo`+`AmmoId`, нож `lrtactical:melee`+`MeleeWeaponId`). Оружие: tacz-паки (cib/maxstuff/rfp) + FCL-пускачи из `pointblank/fcl-ext-0.1.zip` (РПГ-7В2/РПГ-26/M72/AT4/SMAW/Карл Густав) + SBW (только Javelin/Игла/C4/гранаты); броня — только `warbornrenewed:*`. Пистолетные патроны: P320 — `.45 ACP`; M2HB — `tacz:50bmg` (не 127x108); MRAD — `ea:416barrett`. Раскладка: слот 0 — мейн ган (СТВОЛ), слот 1 — пистолет (ВТОРИЧКА), слот 2 — гранаты, **слот 3 — СПЕЦ: фирменное оружие роли** (труба у LAT/HAT, M320 у гренадёра, мины у сапёра, клеймор у снайпера, Игла у ПВО) — у этих ролей дым/бинт сдвинуты на слоты 4-5; метки слотов 0-3 захардкожены в коде (PRIMARY/SECONDARY/THROWABLE/SPECIAL), поэтому спец-оружие лежит физически на слоте 3, а не помечается `__ALT__`
