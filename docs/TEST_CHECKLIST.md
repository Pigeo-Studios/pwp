# Проверка в игре: ветка `rewrite/playable` (19.11.2026)

Всё ниже собрано и покрыто юнит-тестами, но **в игре не проверялось**. Отмечай `[x]`; при провале —
что увидел + строка из `logs/latest.log` (сервер) или клиента. Стенд: лобби + матч-сервер + 2 клиента
(по игроку в команде) + админ-аккаунт (op 2+ или роль admin в БД). Прежний длинный чек-лист — в истории
git (`git show accc88f:docs/TEST_CHECKLIST.md`).

## 0. Подготовка
- [ ] Клиент и все серверы с jar из этой ветки: протоколы `pwpwarfare:main` = **7**, `pwp_core_client:network` = **7**. Старый клиент получает отказ «несовпадение версий канала», не краш.
- [ ] GeckoLib в `mods` = 4.8.4 (компиляция теперь тоже 4.8.4): техника, M2/AGS, РЭБ, анимации оружия рисуются как раньше.

## 1. Цикл матча (игрок)
1. [ ] Лаунчер → лобби: HUD «Ждём игроков M/N», голосование открывается само, J — меню лобби.
2. [ ] Голосование → предпрогрев → перенос на матч-сервер без команд в чате.
3. [ ] Вход в матч: авто-команда (меньшая) или экран команды; без раскладки карты — экран команды, в логе сервера один WARN «Автоназначение команды пропущено…».
4. [ ] Меню отрядов **без команды** (креатив выкл.): кнопки создать/вступить → плашка «Сначала выберите команду», а не тишина.
5. [ ] Отряд → роль → деплой в мейн; мёртвым — рали/ФОБ (отказы с причиной, как раньше).
6. [ ] Метка/путь на карте **не лидером** → «Метки ставят только лидеры отрядов и командиры огневых групп». Удаление чужой метки → «Удалить может только автор или командир».
7. [ ] Стройка лидером: блюпринт дальше 8 блоков → «Слишком далеко…»; без рации в руке → «держите в руке рацию лидера». Обычная постройка — как раньше.
8. [ ] Техника со специалистом: клик «Отправить запрос» в чате, когда лидер вышел → «Лидер отряда не в сети»; машина уже разблокирована → «садитесь без разрешения»; без кита/отряда/в кулдауне — причина над хотбаром. Не-лидер жмёт «Одобрить» → «только лидер отряда».
9. [ ] Бой: захват по порядку AAS, тикеты, нок/подъём медиком (канал 5 с), арта КМД, дроны, ФОБ и эмплейсменты.
10. [ ] Победа по тикетам → экран победы с наградами → через ~15 с все в лобби → следующий матч стартует.
11. [ ] Защита мейна до GO: игрока и технику держит в мейне, чужих выталкивает (код перенесён в `MainZoneGuard` без изменений — проверить, что ничего не сломалось).

## 2. Админ-панель (F6)
Каждое действие: тост «успех/ошибка» в панели + строка в `logs/pwp-admin-audit.log` и во вкладке «Сервер» → «Аудит». Игрок без прав не видит вкладки; присланный вручную пакет → «Недостаточно прав» и строка `DENIED` в аудите.

**Игроки** (MODERATOR+)
1. [ ] Список: ник [команда], строка «Отряд X (лидер) · кит · пинг мс · уровень» обновляется раз в 2 с.
2. [ ] «Телепорт к игроку» → вы рядом с ним (и в другом измерении). На себя → «Выберите другого игрока».
3. [ ] «Наблюдать» → режим наблюдателя с камерой игрока, видно всё (свои и чужие ФОБы/маркеры); повторное нажатие → прежний режим и своя камера. Выйти с сервера в наблюдении и зайти → прежний режим, не наблюдатель.
4. [ ] Варн/кик/мут/бан/перевод в команду/снять тимкилл — как раньше; кик/бан с подтверждением.
5. [ ] (ADMIN, только матч-сервер) «Сбросить кит» (с подтверждением): у игрока пустой инвентарь, роль освобождена (видно в меню деплоя у другого), открылся выбор кита, сообщение «Админ сбросил ваш кит».
6. [ ] «Сбросить кулдауны»: склад/ФОБ-ресапплай и деплой дрона доступны сразу.
7. [ ] «Сделать лидером»: у игрока рация и меню лидера, прежний лидер — боец (сообщение). «Снять лидерство»: переходит другому бойцу онлайн; один в отряде → «В отряде нет других игроков в сети».
8. [ ] На лобби кнопок warfare нет.

**Матч** (ADMIN+)
9. [ ] «Рестарт матча» (подтверждение) во время боя: бой стоп без экрана победы и без записи матча в core, все в мейне без снаряжения, чат «Админ перезапустил матч», начинается ожидание, тикеты/точки из map_config.
10. [ ] «+60 с ожидания» в ожидании → плашка «ПОДГОТОВКА» +1:00; вне ожидания → «не ожидание».
11. [ ] «Победа BLUE/RED» (подтверждение) в бою → обычный экран победы, награды, возврат в лобби; вне боя → «Бой не идёт». Рестарт во время экрана победы → «Матч окончен, сервер возвращается в лобби».
12. [ ] «Перезагрузить map_config» (подтверждение) вне боя: строка «Последняя перезагрузка» = точки/тикеты/слоты/ошибки/замечания; поправить map_config на диске и перезагрузить — изменения применились без рестарта. Во время боя → «Не во время боя…».
13. [ ] «Перезагрузить киты и технику»: строка «Киты и пулы техники» показывает «грузятся (попытка N)» → «✔». Без core → «На сервере нет core-service…».
14. [ ] Старое: старт/стоп/пауза/пропуск ожидания/режим/фракции/тикеты.

**Сервер** (MODERATOR+)
15. [ ] «Этот сервер»: TPS/MSPT/память/игроки/аптайм меняются; при нагрузке MSPT растёт.
16. [ ] «Все серверы»: лобби и матч из heartbeat core (MSPT > 50 — красным); без core → «core-service недоступен».
17. [ ] «Последние предупреждения»: появляются WARN/ERROR сервера, повторы склеены «×N»; **в строках нет ключей/токенов/паролей и IP игроков** (маскируются `***` и `x.x.x.x`).
18. [ ] Объявление: шаблон + «всем/BLUE/RED» → подтверждение → чат и надпись над хотбаром у адресатов на их языке; пустая команда → «В этой команде никого нет».
19. [ ] «Аудит» виден только ADMIN+, модератор раздела не видит.

**Лобби** (ADMIN+, только лобби)
20. [ ] Строка «Подготовка матч-сервера»: «готовится N%» → «ждём голосование» → «переброс»; при сбое — причина текстом (тот же, что в HUD лобби).

**Карта** — без изменений (редактор, замечания валидатора).
