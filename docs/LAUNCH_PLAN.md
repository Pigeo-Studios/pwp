## 1. Закрытая бета (2–3 недели, 30–80 человек)

- **Кого звать:** друзья, знакомые squad-игроки, 1–2 малых сообщества (Discord-серверы Squad/Arma/milsim, русскоязычные MC-серверы с PvP). Приглашение — ключ или whitelist (`whitelist.json` на лобби).
- **Расписание:** 2–3 сессии в неделю по 2–3 часа, фиксированное время (шедулер `pwp-scheduler` + оповещения в TG/Discord уже есть). Пустой сервер в случайное время убивает интерес, людей нужно собрать в одно время.
- **Сбор обратной связи:** канал `#баги` и `#идеи` в Discord, после каждой сессии — короткий опрос из 3 вопросов (что понравилось, что сломалось, придёшь ли ещё).
- **Что мерить:** сколько дошло от лаунчера до первого матча (обучение 5/5), сколько вернулось на вторую сессию, частота крашей (`crash-reports/`), жалобы и баны.
- **Готово, когда:** две сессии подряд без краша сервера, ≥50% вернулись на вторую сессию, топ-10 багов закрыты.

## 2. Открытая бета (1–2 месяца)

- **Анонс:** трейлер 30–60 с (геймплей: деплой → ФОБ → бой за точку → техника), 3–5 шортов (TikTok/Shorts/Reels; канал «Смена Петровича» подходит под шортсы), пост в Discord-сообществах, ВК/Telegram-каналы по Minecraft и Squad.
- **Мониторинги серверов MC** (если подключение — через свой лаунчер, указывать лаунчер, а не IP): описание «Squad в Minecraft: 40 на 40, техника, отряды, ФОБы».
- **Ютуберы/стримеры:** 5–10 средних (5–50 тыс.) по MC-PvP и милсиму — бесплатный VIP/скины + их ивент-матч. Это лучший канал для такого жанра.
- **Ивенты:** еженедельный «большой матч» в выходные в одно время, турнир отрядов/кланов с призами скинами.
- **Сидинг:** первые недели онлайн будет маленьким — включён `seedingBelow` (малые режимы), анонсируй время сбора, а не «заходите когда угодно».
- **Готово, когда:** вечерний пик стабильно ≥ 40 человек, нет критичных багов неделю.

## 3. Релиз и деньги

- Донат только косметический (скины стволов, форма, эмоции), никакого pay-to-win: скины стволов уже меняют только вид. VIP — очередь вне очереди/резервный слот, цвет ника, а не оружие.
- Сайт: страницы на публичном API (`/api/v1/public/*`) — онлайн, топ, профиль, банлист, правила, донат.
- Юридически: правила, политика данных, возвраты платежей; приём платежей — через сервис с договором (не на личную карту).
