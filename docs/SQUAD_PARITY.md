# PWP против Squad: что есть, чего нет, в каком порядке делать (26.11.2026)

Сверка по коду, не по игре. Статусы: ✅ есть · 🟡 частично · ⬜ нет. Порядок очереди — внизу.

## Отряд и командование
| Механика Squad | PWP | Где / чего не хватает |
|---|---|---|
| Отряды, лидер, замок отряда, кик | ✅ | `SquadActions`, `SquadList` |
| Фаертимы (FTL, цвета) | ✅ | `SquadActions`, `SquadPackets` |
| Командир: голосование, способности (UAV, сброс, CAS) | ✅ | `CommanderAbilities` (этап 15) |
| Маркеры лидера (радиалка: атака/оборона/враг…) | ✅ | `SquadMarkerRadialScreen`, `MarkerManager` |
| Споттинг врага (Q) — метка «враг здесь» на 30 с | 🟡 | пинг есть (`PLACE_PING_KEY`), отдельной быстрой метки врага нет |
| Связь: отряд / командный канал / локальный | ✅ | `WarfareVoicechatPlugin`, PTT отряда и команды |
| Ралли лидера, ФОБ-радио, хаб | ✅ | `RallyItem`, `HubBlock` |
| ФОБ: подкоп радио лопатой врага, «overrun» (враги рядом — спавн закрыт) | 🟡 | блок спавна при врагах есть (`blueBlocked`); подкопа радио врагом нет |

## Очередь (по пользе для игры, сверху вниз)
1. ~~17a~~ ✅ — радиальное меню техники и замок машины за отрядом.
2. **17b** — новости: core → главное меню, сайт, лаунчер.
3. **16c** — весь контент в `content/` (киты в 5 строк → дивизии → иконки), `check`/`push`/`pull`.
4. **16b** — площадки техники, таймеры своей техники на карте и в деплое.
5. **17c** — споттинг врага (Q) и подкоп радио ФОБа врагом.
6. **17d** — подавление, серверная выносливость, ремонтный ключ экипажа.

Правило для каждой новой механики (чтобы не было слопа): правила — чистый класс в `pwp-logic` с тестами; сервер решает, клиент только просит; GUI — радиалка на `WarfareRadialScreen` или карточка в «Меню PWP»; текст — lang en/ru/uk; новый пакет — сеть v2 в конце канала + `PROTOCOL_VERSION`.
