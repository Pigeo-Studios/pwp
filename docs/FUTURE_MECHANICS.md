# Future Mechanics — что стоит учесть

## Core / Инфраструктура
- **Auto-create tables** — Core Service сам проверяет и создаёт таблицы при запуске (сейчас schema.sql руками)
- **Heartbeat** — матч-сервера каждые N сек пишут в Core "я жив". Если пропал — лобби пересоздаёт
- **Redis для real-time** — для онлайна, чата, уведомлений между серверами (друзья, приглашения)
- **Offline-режим мода** — если Core упал, игра продолжается, данные кешируются и синхронизируются позже
- **ELO / Rating** — рейтинговая система для баланса команд и соревновательных матчей

## Геймплей / Прогрессия
- **Античит (базовый)** — сервер проверяет: невозможная дистанция убийства, невозможная точность, скорость
- **Карма / Репутация** — за тимкиллы и ранний выход из матча: пониженный приоритет очереди, ограничение китов
- **Кланы** — группы игроков, общий XP бонус, клановые войны, теги
- **Ежедневные/еженедельные задания** — "50 убийств с LMG", "10 захватов" → награды
- **Крафт/апгрейд скинов** — 5 обычных → 1 редкий, 5 редких → 1 эпический и т.д.
- **Трейд скинов** — обмен между игроками (с комиссией)
- **Workshop карт** — игроки создают и загружают свои карты

## Социальное
- **Друзья** — список друзей, приглашения, совместная игра
- **Репорты** — пожаловаться на игрока (чит, токсичность), автоматическая проверка
- **Спектатор** — мёртвые игроки смотрят за тиммейтами (уже частично есть через воскрешение)
- **Replay система** — запись матчей, просмотр после игры

## Интерфейс
- **Туториал / Drill range** — полигон для новичков, обучение управлению техникой
- **Статистика на сайте** — внешний трекер как trackers.gg
- **Поддержка клавиатур (WASD / ESDF)** — настраиваемые клавиши

## Монетизация
- **Боевой пропуск (сезоны)** — каждые 3 месяца, бесплатно + премиум за $10-15
- **Магазин доната** — скины, эффекты, голосовые наборы
- **Бустеры XP/Coins** — 2x на N матчей или N дней
- **Подписка (VIP)** — ежемесячно: +25% XP, эксклюзивные скины, приоритет очереди
