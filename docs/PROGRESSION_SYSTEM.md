# PWP Progression System

## 1. Экономика

### 1.1 Валюта: Coins (монеты)
- **Заработок**: убийства, победы, захват точек, ачивки, ежедневные задания, донат
- **Трата**: скины, эмоции, голосовые наборы, ускорение открытия китов
- **Начисление за матч**:
  ```
          Убийство: +10 Coins
          Ассист:   +5 Coins
          Смерть:   +0 Coins
          Захват:   +25 Coins
          Защита:   +20 Coins
          Ревив:    +15 Coins
          Победа:   +50 Coins
          Поражение: +20 Coins
  ```

### 1.2 Опыт: XP
- **Заработок**: все игровые действия + время игры
- **Начисление за матч**:
  ```
          Убийство игрока:      +50 XP
          Убийство техники:     +150 XP
          Ассист:               +25 XP
          Захват точки:         +100 XP
          Ревив:                +75 XP
          Строительство FOB:    +100 XP
          Поставка припасов:    +50 XP
          Время (за минуту):    +10 XP
          Победа:               +200 XP
  ```

### 1.3 Уровни и престижи
- Каждый уровень требует: `level * 1000 XP` (1→1000, 2→2000, ..., 100→100000)
- Каждые 10 уровней — достижение + награда
- **Престиж** (Prestige): после 100 уровня можно сбросить до 1 с особым значком
  - Престиж 1: серебряная нашивка
  - Престиж 2: золотая нашивка
  - Престиж 5: бриллиантовая нашивка

## 2. Ранги (как в Squad)

Ранги определяют, какие киты/роли доступны игроку.
Всего 20 рангов, от "Recruit" до "Marshal".

| 7 | Staff Sergeant | 12,000 | Pilot, Mechanic |
| 8 | Sergeant First Class | 18,000 | HAT |
| 9 | Master Sergeant | 25,000 | Sniper |
| 10 | First Sergeant | 35,000 | Drone Operator |
| 11 | Sergeant Major | 45,000 | Anti_air |

### Как работает анлок китов:
1. Игрок в лобби видит список китов с замками
2. Наведение показывает: "Требуется ранг Sergeant (8,000 XP)"
3. При достижении ранга — всплывающее уведомление
4. В матче: неоткрытый кит нельзя выбрать

## 6. Система скинов (Cosmetics)

### Слоты
```
KNIFE      — ножи (визуал + анимация)
PRIMARY    — основное оружие
SECONDARY  — пистолеты
UNIFORM    — униформа / камуфляж
HEADGEAR   — головные уборы
PATCH      — нашивки (ранг, ачивки, клан)
EFFECT     — эффекты (убийство, получение, спавн)
VOICE      — голосовые наборы
ANIMATION  — эмоции / победы
```

### Редкости
```
COMMON    — серая      — базовые, из шопа за 500 coins
RARE      — синяя      — шоп 2,000 coins / ачивки
EPIC      — фиолетовая — шоп 5,000 coins / сезон
LEGENDARY — золотая    — шоп 15,000 coins / донат / высокие ранги
MYTHIC    — красная    — только за достижения / ивенты
```

### Экипировка по ролям
Игрок может настроить: "Для класса Medic — красный нож, для Sniper — чёрный".
Это хранится в таблице `player_equipment` с полем `role`.

## 7. Боевой пропуск (Seasons)

- Длится ~3 месяца
- Бесплатная дорожка: базовые скины, монеты, XP бустеры
- Премиум дорожка ($10-15): легендарный скин, эксклюзивные эмоции, 2x XP
- 50 уровней пропуска
- XP для уровня пропуска: `season_level * 2000 XP`

### Пример наград:
```
Уровень 1  (free)    — 100 Coins
Уровень 1  (premium) — Легендарный нож "Dragon Fang"
Уровень 10 (free)    — Скин на AK "Woodland"
Уровень 10 (premium) — Эффект убийства "Огонь"
Уровень 25 (free)    — 500 Coins
Уровень 25 (premium) — Скин на униформу "Black Ops"
Уровень 50 (free)    — Нашивка "Season 1 Veteran"
Уровень 50 (premium) — Легендарный скин на M4 + эксклюзивный эмоция
```

## 8. Интерфейс: что где показывать

### Лобби (PWP Lobby)
```
— Таблица статистики (K/D, winrate, playtime)
— Список скинов с предпросмотром (3D вращение через GeckoLib)
— Магазин скинов (сортировка по редкости/слоту/цене)
— Прогресс-бар ранга (текущий уровень, XP до следующего)
— Достижения (категории, прогресс, награды)
— Выбор экипировки по ролям (сетка слотов)
— Боевой пропуск (уровни, награды free/premium)
```

### Экран смерти
```
— Кто убил, чем, с какого расстояния
— Твой счётчик: убийства/смерти/ассисты за матч
```

### После матча
```
— Детальная статистика:
    K/D/A, score, captures, revives, vehicle kills
    accuracy, longest kill
— Начисление XP и Coins (анимированный счётчик)
— Полученные достижения (всплывают одно за другим)
— Полученные предметы / скины
— Кнопка "Назад в лобби"
```

### В игре (HUD)
```
— Текущее: kills, deaths, score (только за этот матч)
— На табло (Tab): ранги + скины игроков (как в CS2)
```
