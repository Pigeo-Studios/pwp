# PWP — «Squad в Minecraft»

Тактический командный шутер на Forge 1.20.1 (Java 17): команды, отряды и лидеры, ФОБы и ралли, тикеты,
точки захвата, медицина, техника по дивизиям фракций. Режимы: **AAS**, **Invasion** и малая **«Стычка»** под
небольшой онлайн.

## Из чего состоит

| Часть | Что это |
|---|---|
| `pwp-core` | мод (клиент + серверы): лобби и голосования, меню и UI-кит, админ-панель F6, косметика, магазин, клиент API core-service |
| `pwp-game` | мод (клиент + серверы): матч — отряды, ФОБ/ралли, техника и дивизии, дроны, медицина, лимиты боя, HUD, редактор карты |
| `sbwchunkload` | серверный мод: прогрузка чанков для снарядов и дронов SBW |
| `pwp-logic` | чистая логика без Minecraft + быстрые тесты (`gradlew :pwp-logic:test`), компилируется внутрь модов |
| `core-service` | HTTP API + MySQL: игроки, экономика, киты, техника, дивизии, карты, античит (`core-service/gradlew shadowJar`) |
| `bots/`, `pwp-scheduler/` | Telegram/Discord-боты и шедулер серверов (Python) |
| `maps/` | конфиги карт, киты (`maps/kits`), техника и дивизии (`maps/vehicles`) |

На клиенте, лобби и матч-серверах лежат **одни и те же 3 jar**.

## Сервер одной командой

Нужно: JDK 17 (`C:\Program Files\Java\jdk-17`), папка `Pwpfiles` рядом с репозиторием (или переменная
`PWPFILES_DIR`), готовый Forge-сервер лобби и шаблон матча `PWP-Server\match_template` рядом с лобби.

```powershell
powershell -ExecutionPolicy Bypass -File tools\pwp-server.ps1 -Build -Start -Server "C:\srv\lobby","C:\srv\PWP-Server\match_template"
```

Скрипт собирает моды с тестами, проверяет reobf, перекладывает старые jar PWP в `mods_backup_<дата>`, кладёт
3 новых и запускает лобби. Дальше всё крутится само: лобби набирает игроков → голосование (карта → режим →
фракции) → поднимает матч-сервер из шаблона → переброс → бой → итоги → все обратно в лобби → следующее
голосование. Пустой или бесконечный матч сервер гасит сам (сторож матча).

**Полный локальный сервер** (MariaDB + core-service + лобби + матчи, всё на 127.0.0.1, offline) — тест-стенд
`Desktop\PWP-TestLobby` + `%USERPROFILE%\pwp-local`:

```powershell
powershell -ExecutionPolicy Bypass -File tools\pwp-local.ps1 -Build -Start
```

Скрипт собирает моды и core-service, раскладывает jar в лобби, шаблон матча и Prism-клиент, поднимает базу
(при первом запуске сам создаёт `pwp_core`, при пустых дивизиях импортирует стартовые), затем core и лобби.
Без `-Start` только раскладывает jar.

**Панель управления** — `tools\pwp-control.cmd` (двойной клик). Это окно со всеми частями сервера: база, core, лобби
и каждый матч отдельной строкой. Состояние обновляется раз в 2 с, у матча видна стадия.

- Для выбранной строки: «Старт», «Стоп», «Убить процесс», «Папка», «Лог».
- Для всего сервера: «Запустить всё», «Остановить всё», «Собрать и разложить», «Проверить контент».
- Консоль лобби: «Статус матчей», «Начать голосование», «Остановить матч», «Игроки» или любая команда.

Внутри игры каждым сервером управляет его админ-панель F6. Без окна: `tools\pwp-control.ps1 -Status`.

**Проверка контента без игры** — `py -3 tools\pwp_doctor.py` (то же, что кнопка в панели). Проверяет:

- киты: слоты, свои предметы, оружие из настоящих ганпаков Pwpfiles;
- пулы техники и дивизии: машина дивизии есть в пуле фракции;
- карты: фракции и слоты техники;
- переводы: ключ из кода есть в en/ru/uk.

Ошибка — в игре сломается, предупреждение — стоит посмотреть.

Настройки сервера — один файл `config/pwp-server.json` (создаётся при первом старте):

```json
{
  "role": "auto",
  "lobby": { "autostart": true, "maxMatches": 2, "minPlayers": 1, "prewarm": false },
  "matchServers": { "template": "../PWP-Server/match_template", "basePort": 25566 },
  "mapsDir": ""
}
```

`role`: `auto` — папка `match_*` значит матч-сервер, иначе лобби. Ключ core-service — переменная
`PWP_API_KEY` или `config/pwpcore.txt`. Баланс боя (кулдауны, тикеты за ФОБ, лимит матча) — Forge-конфиги
`config/pwpwarfare-common.toml` и `<мир>/serverconfig/*.toml`.

Ключ нужен всегда. Если core-service не запущен, сервер всё равно работает, но без профилей, наград и
китов из БД (киты берутся из мира).

## Карта за 10 минут

1. **Мир.** Содержимое папки мира (`level.dat`, `region/`…) положи прямо в `maps/<имя>/` на машине лобби, рядом
   будет лежать `map_config.json`. Лобби копирует эту папку в каждый новый матч-сервер.
2. **Минимальный `maps/<имя>/map_config.json`:**
   ```json
   {
     "name": "myfield",
     "displayName": "My Field",
     "maxPlayers": 40,
     "minPlayers": 2,
     "availableFactions": ["usa", "russia", "ukraine", "nato", "insurgency", "pmc"],
     "modes": { "skirmish": {} },
     "teams": {
       "BLUE": { "faction": "usa", "tickets": 600 },
       "RED":  { "faction": "russia", "tickets": 600 }
     },
     "settings": { "respawnTimer": 15, "deathTicketCost": 2 }
   }
   ```
   `"skirmish"` в `modes` добавляет «Стычку» в голосование. Это малый режим: точки берутся в любом порядке,
   техники нет. AAS и Invasion доступны всегда.
3. **Раскладка в редакторе.** Зайди на матч-сервер с этой картой (op 2+ или роль admin), нажми Esc и выбери
   «Редактор карты». Там нужно:
   - мейны BLUE/RED: два угла ЛКМ/ПКМ по блокам в режиме «Ставить в мире»;
   - спавн мейна (иначе берётся центр мейна);
   - точки захвата и их порядок: перетаскивание строк, нумерация BLUE→RED считается сама;
   - слоты техники с ролью (TRANSPORT/APC/TANK…): машину подставит дивизия фракции;
   - граница зоны (иначе бокс мейнов и точек + 32).
4. **«Для старта».** Красных замечаний быть не должно: с ними матч не стартует, жёлтые допустимы.
   - «Применить на этот матч» — чтобы попробовать сразу;
   - «Сохранить навсегда» (OWNER) — раскладка уходит в core-service и подгружается на каждом старте.
5. Готово: карта появится в голосовании лобби. Техника выставится по дивизиям фракций. Стартовые дивизии
   создаются так: `py -3 tools/generate_divisions.py`, затем импорт `maps\vehicles\divisions.sql` в БД через
   `cmd /c "mysql ... < ..."`.

## Сборка и тесты

```powershell
.\gradlew.bat build
```

```powershell
.\gradlew.bat :pwp-logic:test
```

```powershell
py -3 tools\check_reobf.py
```

Первая команда — моды и все тесты, со spotless и гарантией reobf. Вторая — чистая логика, ~3 с. Третья —
проверка готовых jar перед деплоем. Форматирование: `gradlew spotlessApply`.
