## Что меняется в коде

### 1. DeployLayout (пересчёт)
- left 25% (отряды, вся высота) — БЕЗ изменений.
- middle 25%: сверху МАЛЕНЬКИЙ бокс ролей (~150px: 4 ряда × 24px + заголовок),
  ниже ОДИН бокс «спавн+чат» (остаток высоты).
- right 50%: зона карты/лоаудата; внутри лоаудата: слоты (слева ~65%) + солдат (справа ~35%).
- Новая зона в layout: `loadoutCards` + `loadoutSoldier` (вместо loadoutSlots/soldier).

### 2. RolesPanel — «маленький бокс ролей»
- Ячейки МАЛЕНЬКИЕ (~24px, фикс), отступ 1-2px, БЕЗ текста под иконками (только иконка;
  счётчик n/m мелко при лимитах).
- Всё умещается в ~4 ряда (COMMANDER: 3 роли в ряд; остальные категории рядом).
- Категории — тонкие линии-разделители (без заголовков-строк, либо микро-подпись).
- Тултип с именем роли при hover (с задержкой).
- Клик по доступной роли → выбор; hover/клик → лоаудат (hover — выдвинул, клик — закрепил).
- Категории/названия ролей — из DeployData (KIT_GROUP/display names), как сейчас.

### 3. SpawnChatPanel — НОВЫЙ единый бокс «спавн + чат» (замена SpawnListPanel + ChatPanel)
- Верх бокса: строка выбранного спавна [иконка][название (A1-2-3)][статус][▾ стрелочка справа].
- Клик по стрелочке/строке → раскрывается список спавнов (строки с иконками/координатами/статусом);
  при раскрытии ВЫСОТА ЧАТА УМЕНЬШАЕТСЯ (чат остаётся видимым, но меньше).
- Ниже: чат (канал [ALL/TEAM/SQD] + инпут + 3 строки истории).
- Один визуальный бокс: общая подложка/заголовок (SPAWN SELECT) — чат без отдельной рамки.
- Клик по спавну → выбор + синк карты; повторный клик по стрелочке → свернуть.
- Выбранный спавн — жёлтая рамка; недоступный — затемнён, не кликается.

### 4. LoadoutPanel — новая структура карточек
- PRIMARY: карточка СВЕРХУ НА ВСЮ ШИРИНУ (высокая): 3D-витрина оружия (справа в карточке),
  название, магазины, шеврон при альтернативах → дропдаун под ней (как сейчас).
- SECONDARY | SPECIAL: ДВЕ карточки РЯДОМ (каждая ~половина ширины),
  ОБЩИЙ размер = размеру PRIMARY (высота той же).
- BACKPACK: 4 ячейки в ряд (как карточка SECONDARY, разделённая пополам, и SPECIAL — пополам);
  дополнительные слоты — следующими рядами ниже.
- ОПИСАНИЕ ОРУЖИЯ (статы/текст) — ниже карточек.
- Солдат НЕ в этом боксе — рисуется справа отдельной зоной (болванка), см. layout.
- Дропдаун под PRIMARY, живая витрина, статы TACZ — сохраняются.

### 5. PortraitRenderer — зона справа (~35% правой колонки)
- Кукла на всю высоту, чуть правее центра зоны, имя роли + зелёная полоска + описание снизу.
- Драг-вращение, ПКМ-сброс — как сейчас.

### 6. Интеракция карта ⇄ лоаудат
- hover по боксу ролей → лоаудат ВЫДВИГАЕТСЯ (слайд+fade, как сейчас);
- клик по боксу ролей (или клик в лоаудауте) → ЗАКРЕПЛЯЕТСЯ (pinned);
- уход курсора → карта возвращается, если не закреплено; ESC/клик мимо — снять закрепление.

### 7. Мелочи
- Карта: без изменений (иконки/сетка A1-2-3/тултипы — ок).
- Звуки/хоткеи/три состояния — сохраняются.
- ChatPanel.java и SpawnListPanel.java — заменяются на SpawnChatPanel (файлы удалить).
- DeployState: добавить `pinnedLoadout` флаг.
