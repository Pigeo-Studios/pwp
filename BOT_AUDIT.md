## 7. Вход (login)

### Если Telegram уже привязан к аккаунту:
```
[🔑 Войти]
→ 🔑 К этому Telegram привязан аккаунт AnquineNFT. Войти?
  [✅ Да, войти как AnquineNFT] [❌ Нет]
→ [✅ Да] → Введите пароль → Вход выполнен ✅ + MAIN_MENU
```

### Если Telegram НЕ привязан:
```
[🔑 Войти]
→ Введите ваш логин
→ Введите пароль
→ Вход выполнен ✅ + MAIN_MENU

На каждом шаге: [⬅ Назад] [🏠 Главная] [❌ Отмена]
```

### Выход:
```
[🚪 Выйти]
→ 🚪 Вы уверены, что хотите отвязать Telegram от аккаунта?
  [✅ Да, выйти] [❌ Нет]
→ Вы вышли из аккаунта. Telegram отвязан.
```

## 10. Регистрация (REGISTRATION_FLOW)

### Проверка перед стартом:
Если `profile-by-tg` находит аккаунт → `❌ Этот Telegram уже привязан к аккаунту. Используйте кнопку «Войти».`

### Шаги:
```
Шаг 1 из 4: Введите логин (3-32, латиница/цифры/_)
  → проверка check-login (API) → занят? ❌ Этот логин уже занят
  → API не отвечает? ❌ Сервис недоступен

Шаг 2 из 4: Введите e-mail
  → проверка check-email (API) → занят? ❌

Шаг 3 из 4: Придумайте пароль (8+ символов, загл. буква, цифра)
  → ошибка: ❌ Пароль не подходит: • минимум 8 символов

Шаг 4 из 4: Подтверждение
  Логин: AnquineNFT
  Email: a***@gmail.com
  [✅ Создать] [✏️ Изменить] [❌ Отмена]

→ Создать → register (API)
  → Успех: ✅ Аккаунт создан! + MAIN_MENU
  → Ошибка "уже зарегистрирован": [🔑 Войти] [❌ Отмена]
  → Другая ошибка: ❌ {текст ошибки}

На каждом шаге: [⬅ Назад*] [🏠 Главная] [❌ Отмена]
*⬅ Назад возвращает на предыдущий шаг, не сбрасывая данные
```

## 13. FSM (Finite State Machine)

| State | Описание | Принимает текст? |
|-------|----------|-----------------|
| `IDLE` | Ожидание /start | Нет |
| `MAIN_MENU` | Главное меню | Нет |
| `REG_LOGIN` | Регистрация: ввод логина | Да |
| `REG_EMAIL` | Регистрация: ввод email | Да |
| `REG_PASSWORD` | Регистрация: ввод пароля | Да |
| `REG_CONFIRM` | Регистрация: подтверждение | Нет (кнопки) |
| `PASS_OLD` | Смена: старый пароль | Да |
| `PASS_NEW` | Смена: новый пароль | Да |
| `PASS_CONFIRM` | Смена: подтверждение | Да |
| `LOGIN_LOGIN` | Вход: логин | Да |
| `LOGIN_PASSWORD` | Вход: пароль | Да |
| `RESET_NEW` | Сброс: новый пароль | Да |
| `RESET_CONFIRM` | Сброс: подтверждение | Да |
| `ADMIN_SEARCH` | Админ: поиск пользователя | Да |
| `ADMIN_BAN_REASON` | Админ: причина бана | Да |
| `ADMIN_BROADCAST` | Админ: текст рассылки | Да |

Текст принимается **только** в состояниях где написано «Да». Во всех остальных — игнорируется.

## 14. Безопасность

- **Rate limit:** check-login (30/мин), login (10/мин), forgot-password (3/мин)
- **Admin endpoints** требуют `X-Admin-UUID` header + роль admin/owner
- **2FA код** не возвращается в HTTP ответе
- **Email** валидируется regex
- **Processing lock:** `session.processing` блокирует двойные вызовы
- **Пароль** очищается из памяти сразу после регистрации
- **Причина бана** не возвращается в ошибке логина
- **Profile** не возвращает `last_ip`
- **Broadcast** не возвращает список Telegram ID
