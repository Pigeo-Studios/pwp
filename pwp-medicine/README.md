# PWP Medicine

**Forge 1.20.1 | Зависимость: GeckoLib 4.4.9 | Server-side config**

Медицинская система: бинты, аптечки, кровотечение, пассивные эффекты по ХП.

### Предметы

- **Бинт** — время использования 40 тиков (2 сек). Лечит 6 HP, но не выше 14 HP. Снимает кровотечение. Анимация GeckoLib. Можно использовать на себе или на союзнике в радиусе 3 блоков.
- **Аптечка** — постоянное использование (hold). Лечит по 2 HP каждые `medkitApplyTime` тиков (по умолч. 40 тиков = 2 сек). До полного ХП. Не работает при кровотечении. Анимация GeckoLib с анимациями use_start/use_end/idle.

### Эффекты

- **Кровотечение** — длится 12000 тиков (10 мин). Урон 1 HP каждые 40 тиков (2 сек). При ХП ≤ 1 наносит 10 урона типом `pwp_medicine:bleeding`. Цвет — красный. При наложении запоминает атакующего для сообщения о смерти. Не накладывается: на игроков верхом, в нокауте, или если урон ниже порога. Шанс наложения — `bleedingChance` (по умолч. 20%).
- **Пассивные эффекты по ХП (серверные, каждые 40 тиков):**
  - ХП ≤ 14: тошнота I + слабость I + периодическая тошнота каждые 300 тиков. Флаг срабатывает один раз.
  - ХП ≤ 10: слабость II + тошнота каждые 200 тиков.
  - ХП ≤ 6: тошнота II + слепота + слабость III + тошнота каждые 100 тиков.
  - ХП ≤ 1: игрок в нокауте (PWP_IsDowned) — кровотечение снимается.

### Конфиг

`<мир>/serverconfig/pwp_medicine-server.toml`

- `medkitApplyTime` (int, 1–72000, default 40) — тиков между тиками лечения аптечки
- `bleedingDamageThreshold` (double, 0.0–1000.0, default 3.0) — минимальный урон для шанса кровотечения
- `bleedingChance` (double, 0.0–1.0, default 0.2) — шанс кровотечения при получении урона выше порога

### Особенности

- При смерти игрока кровотечение снимается и удаляется из карты источников.
- В нокауте (downed) кровотечение не тикает и снимается.
- Урон от кровотечения не вызывает повторное кровотечение (проверка на `BLEEDING_DAMAGE_KEY`).
