# PWP Limits

**Forge 1.20.1 | Server-side config | Client-side effects**

Ограничения геймплея для милитари-режима.

### Возможности

- **Кулдаун спринт-прыжка** — блокирует прыжок во время спринта на заданное время (по умолч. 3 сек). Настраивается серверной конфигурацией.
- **Кастомная полоса здоровья** — заменяет ванильную, с плавным появлением/исчезновением. Появляется при изменении здоровья или при активном кулдауне прыжка.
- **Индикатор кулдауна** — тонкая полоса прогресса под здоровьем.
- **Скрытие ванильного HUD** — здоровье, еда, хотбар, XP, броня, прицел — всё убрано.
- **Блокировка F3/F5** — в выживании и приключении отключает отладку, хитбоксы и третье лицо.

### Конфиг

`<мир>/serverconfig/pwplimit-server.toml`

- `enableJumpCooldown` (true/false) — включить кулдаун
- `jumpCooldownSeconds` (0.1–60.0, default 3.0) — длительность кулдауна
