━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

>>> 🎯 ***Rifleman (стрелок / рифла)*** — ***лучший выбор для новичка.***
Стреляй, носи сумку (ящик с патронами), пополняй `#сквадной`, медика и трубачей.

***Другие роли (пробуй после рифлы):***

🚑 ***Medic (медик / хилер)***
Носишь аптечку, поднимаешь людей. Держись чуть позади отряда. ***Не герой*** — живой медик полезнее двух мёртвых. Приоритет: сквад → синяки.

💥 ***LAT (труба / трубач)***
Лёгкий противотанкист. Выносишь лёгкую технику (мотолыги, мрапы, сопли, пехотки). ***~~Не трать выстрелы на пехоту~~***.

🔥 ***HAT (тандем / тандемщик)***
Тяжёлый ПТ. Бронебойные боеприпасы для тяжёлой техники. Требует опыта.

🔫 ***LMG / HMG (пулемётчик)***
Подавление огнём. Нашёл позицию — лёг, подавляй, не дёргайся.

💣 ***GP (подствольник / карандашник)***
Гранатомётчик. ЗаГПшить скопление врагов, выкуривать из зданий — имба класс.

🎯 ***Marksman (плётка)***
Полуавтомат с оптикой. Для прикрытия. Хорош только если реально умеешь стрелять.

||🎖️ ***Officer*** — кит только для `#сквадной`. Если ты не SL — не бери, сервер выкинет.||

🩺 ***__МЕДИЦИНА__***
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🩸 ***Кровотечение***
После сильного попадания есть шанс что пойдёт кровь. Ты «течёшь». Останавливается ***только бинтом***. Носи бинт ***всегда***.

🩹 ***Бинт / повязка***
Юзай если идёт кровь. 2 сек, лечит до 14 хп, расходуется. Если не перевязаться — истечёшь.

💊 ***Аптечка***
Если нет крови и хп ниже макс — держи ПКМ, выхилит до полного. ***Сначала бинт, потом аптечка.***

😵 ***Нок (нокаут)***
Смертельное попадание, но ты ещё жив. Лежи, зови медика в войс, ***не гивайся сразу***.

🏳️ ***Гивап (Give Up)***
Сдаться и появиться заново. Тратит тикет команды. Только если медик не дойдёт.

>>> ***Порядок лечения от медика:***
1. Поднял бойца (ревайвнул)
2. Перевязал бинтом, если кровь
3. Восстановил здоровье аптечкой
4. Перешёл к следующему

>>> ||🚛 ***Сопля / суплайка*** (Supply truck)|| — грузовик с ресурсами (ресами). ***Самая важная машина.*** Возит стройматериалы для фоб. 1 сопля = 2 ящика = 100 ресов. ***~~Не уводи соплю покататься~~*** — `#сквадной` проклянёт.

||🚗 ***Пехотка***|| — просто транспорт для людей. Не может возить ресы.

||🛻 ***Танки, БТРы, вертолёты***|| — если не ***мехвод / пилот*** — не садись, сервер выкинет через 5 сек.

> 📌 ***Клейм техники:*** Технику надо заклеймить до того как сесть за руль. Либо называешь сквад `«Танк / Верт / ПТУР»` (неймклейм).

Если техника дымит — вези на ремонт на мэйн (чинилка). ***Не бросай технику.*** Если горит — выпрыгивай. Слитая техника = штраф по тикетам.
