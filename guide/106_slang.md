📖 ***__СЛОВАРЬ СЛЕНГА__***
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

||***А***||
┣ ***Азимут*** — направление по компасу на врага. В локальный чат: «Азимут 228, высокие камни, внизу»
┗ ***Актуал*** — точка, открытая для захвата / обороны сейчас

||***Б***||
┣ ***Бинт / повязка*** — перевязочный пакет. Снимает кровь, лечит до 14 хп
┣ ***Блок мэйна*** — перехват врага возле мэйна
┗ ***Блок хаба (прокси блок)*** — враг рядом с хабом → спавн гаснет

||***В***||
┗ ***Вытекаю*** — в ноке и таймер на 0. Или кровь и нечем перевязаться

||***Г***||
┣ ***Гивапаться / килятся*** — сдаться, возродиться (Give up)
┣ ***ГП (гранатомётчик / подствольник / карандашник)*** — класс с подствольником
┣ ***ЗаГПшить / загэпэшить*** — обстрелять гранатомётом
┗ ***Гусеница / гусеничное*** — любая гусеничная техника

||***Д***||
┣ ***Двойной забел*** — обе команды забелили точки → захват невозможен
┣ ***Девяностик*** — танк Т-90А
┗ ***ДРГ*** — диверсионно-разведывательная группа

||***З***||
┣ ***Забел*** — точка из вражеской → в нейтральную (белую)
┗ ***Зушка*** — ЗУ-23 (постройка или на техничке)

||***И***||
┣ ***Ивент*** — событие с сюжетом и правилами
┗ ***Инженер / сапёр / минёр*** — класс для разрушения

||***К***||
┣ ***Карандаш*** — осколочный боеприпас ПТ гранатомёта
┣ ***Кит*** — роль / класс (Kit)
┣ ***Квадрат*** — сетка карты: «D4»
┣ ***Клейм*** — заявка на технику (Claim). Неймклейм — отряд под технику
┣ ***КМД / ЦМД*** — командир стороны
┣ ***Контест*** — на точке и свои, и враги → захват не идёт
┣ ***Корова, амтрак*** — бронетранспортёр морпехов США
┗ ***Кэп, тянуть*** — захватывать точку (Capture)

||***Л***||
┣ ***Лавка*** — LAV III / LAV 6 / LAV-25
┣ ***ЛАТ (Light Anti-Tank)*** — лёгкий ПТ, трубач
┣ ***Локал*** — локальный (синий) войсчат
┗ ***Лычки / галочки / шевроны / стрелочки*** — значки под флагом на точке

||***М***||
┣ ***Марксман / плётка*** — полуавтомат с оптикой
┣ ***МГ / машинганер*** — пулемётчик
┣ ***Медик / медос / хилер / доктор / корпсман*** — класс лечения
┣ ***Мэйн*** — главная база (Main base)
┣ ***Метка / маркер*** — от SL или ФТЛ на карте
┣ ***Мехвод / крювмен*** — водитель техники
┣ ***Миномёт / миномётка*** — постройка для непрямого огня
┣ ***Молотки*** — ресурс для строительства
┣ ***Мотолыга*** — МТ-ЛБ
┗ ***Мрап*** — M-ATV

||***Н***||
┣ ***Неймклейм*** — отряд = техника («Танк», «Верт»)
┣ ***Нок*** — нокаут (Knock-down)
┗ ***Нумпад*** — подквадрат (цифры 1-9)

||***О***||
┣ ***Оптика*** — стрелок с оптическим прицелом
┗ ***Ополченцы / сербы / бомжи*** — ополчение (иррегуляр)

||***П***||
┣ ***Патронник*** — ящик с боеприпасами
┣ ***Пех / пехотный сквад*** — обычный отряд
┣ ***Пехотка*** — транспорт только для людей
┣ ***Повстанцы / талибы / душманы / бомжи*** — Insurgents
┣ ***ПТРК / ТАУ / ТОВ / ПТУР*** — противотанковая ракета
┗ ***Птуровозка*** — техника с ПТРК

||***Р***||
┣ ***Радик / рация / радейка*** — радиостанция FOB
┣ ***Ралик*** — точка сбора (Rally point)
┣ ***РВС (RWS)*** — дистанционное управление оружием
┣ ***Ресаться*** — возрождаться
┣ ***Ресы*** — стройматериалы (Resources)
┣ ***Разрес*** — массовый спавн по команде
┣ ***Рейдер / жандарм / амбушер*** — штурмовик для ближнего боя
┣ ***Рифла / стрелок / штурмовик*** — Rifleman
┗ ***Руин*** — вредительство своей команде (Ruin)

||***С***||
┣ ***Синяк*** — союзник из другого отряда (синий)
┣ ***Сишка / C4*** — взрывчатка
┣ ***Сквад*** — отряд (Squad)
┣ ***Сквадной / SL / сквадлидер*** — командир отряда
┣ ***Снабженцы*** — отряд подвоза ресурсов
┣ ***Сопля / суплайка / саплай*** — транспорт снабжения (Supply)
┣ ***Стройбат*** — отряд для строительства
┗ ***Сумка*** — ящик с патронами от рифлы

||***Т***||
┣ ***Тандем / тандемщик / ХАТ*** — тяжёлый ПТ
┣ ***Тапок*** — TAPV (канадский бронеавтомобиль)
┣ ***Тех*** — отряд «техника»
┣ ***Техничка*** — пикап с оружием
┣ ***Тикеты*** — очки команды (Tickets)
┣ ***Тикет-блид*** — утечка тикетов
┣ ***ТК / тимкилл*** — убийство своих
┣ ***Триггер*** — зона захвата точки
┣ ***Тридцатка*** — техника с 30-мм автопушкой
┗ ***Труба / трубач / карандаш*** — ПТ гранатомёт

||***Ф***||
┣ ***Фаертим / Fireteam*** — подгруппы (Альфа, Браво, Чарли)
┣ ***ФТЛ*** — Fireteam leader
┗ ***Фоба*** — FOB (рация + радиус стройки)

||***Х***||
┣ ***Х часов*** — направление по циферблату
┣ ***Хаб*** — HAB, точка возрождения у FOB
┣ ***Хаб в блоке*** — заблокирован из-за врага
┣ ***Закрытый хаб*** — в здании (устойчив к миномётам)
┣ ***Открытый хаб*** — на земле (уязвим)
┣ ***Хотдроп (hot drop)*** — высадка прямо у врага
┗ ***ХАТ*** — Heavy Anti-Tank, тяжёлый ПТ

||***Ч***||
┗ ***Чинилка / ремонтка*** — станция ремонта БК на мэйне

||***Ш***||
┣ ***Шеврон*** — стрелка на полосе захвата
┗ ***Шахид мобиль*** — транспорт со взрывчаткой для тарана
