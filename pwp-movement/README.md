# PWP Movement

**Forge 1.20.1 | Client-side only | Нет конфига**

Иммерсивное передвижение: усталость, инерция, кастомный хотбар.

### Возможности

- **Наклон камеры** — плавный крен при стрейфе (влево/вправо).
- **Инерция на земле** — горизонтальная скорость умножается на 0.95 каждый тик, движение тяжелее.
- **Оглушение при приземлении** — после любого падения скорость временно снижается (до ~30%), затухает за ~8 тиков.
- **Усталость при спринте** — накапливается за ~4 сек бега, спадает за ~6 сек отдыха. Влияет только на камеру.
- **Качание камеры** — при усталости камера плавно раскачивается по рысканью и тангажу. Амплитуда зависит от усталости.
- **Динамический FOV** — при спринте FOV увеличивается пропорционально скорости.
- **Кастомный хотбар** — анимированный: выезжает снизу, через 2.5 сек бездействия прячется. Выбранный слот приподнят на 10px.

### Конфиг

Нет. Все значения хардкодные. Пулл-реквесты с выносом в конфиг приветствуются.
